# 2025-12-04 GENA-A 一路触发与最终筛选产出

## 问题和定义

检验的是 A 探头在一路有信号的下传记录增多时，按当前 `gena/filter.py` 筛选得到的最终事件比例升高还是降低。这里不使用包内 `EvtLevel` / `EvtEff` 标志判断事件是否有效，也不把已保存的历史 L2G 直接当作现行筛选结果。

分母为 `triggered_eff`：A 探头八路位置 TDC 中至少一路非零。原始索引值大于 94 才对应转换后非零 TDC。中间阶段为 `start_stop_eff`，即八路全部非零。最终分子为八路齐全的 L1A 通过 A 探头 `golden_std(params=init_param(1))`，并在逐行对应的 L2 上通过 `onboard_eff(c_size=[150, 60])` 的记录数。这一顺序与当前 `gena.raw.decode` 的 L2G 生成流程一致。`golden_std` 包括起止通道的长度、先后、求和、差值以及 X/Y 飞行时间一致性条件。

所有速率和比例都基于**已下传的记录**。五分钟箱内触发率为该箱一路有信号的记录数除以 300 秒；它不是探测器前端全部触发的计数率。研究时段为 2025-12-04 08:25 至 2025-12-06 00:00 UTC，五分钟分箱。原始八路齐全计数与已保存 A 探头 L1A 逐箱完全一致；A 的 L1A/L2 逐行事件标识一致；直接运行 `golden_std` 与 `soft_std & tofxy_eff` 的逐行掩码一致。

## 事件窗与相邻对照

E1 为 12-04 14:10–15:40 UTC，邻近时间窗为 12:00–14:10 与 15:40–17:20；E2 为 17:20–18:30，邻近时间窗为 16:30–17:20 与 18:30–19:10；E3 为 21:20–12-05 01:10，邻近时间窗为 20:00–21:20 与 01:10–02:00。此前图中的 `control` 仅指增强前后的邻近时间，并没有证据证明这些时间的鹊桥二号处于等离子体 quiet 环境。各比例先汇总时段内的计数再相除。

| 时段 | A 下传一路触发率，事件 / 对照 (s⁻¹) | 八路齐全 / 一路触发，事件 / 对照 | 当前最终 / 一路触发，事件 / 对照 |
|---|---:|---:|---:|
| E1 | 754.5 / 906.6 | 1.718% / 0.0776% | 0.8165% / 0.0234% |
| E2 | 805.3 / 938.5 | 1.161% / 0.0871% | 0.4386% / 0.0309% |
| E3 | 845.4 / 882.6 | 0.4793% / 0.1191% | 0.2028% / 0.0422% |

三个 ENA 增强时段的 A **下传**一路触发率都低于合并的相邻对照，然而八路齐全比例和最终比例都更高。最终比例分别为合并对照的约 34.9、14.2、4.8 倍。最终绝对比例仍不到 1%，所以“绝大多数一路触发没有进入最终产品”与“事件窗相对邻近时段的通过率上升”同时成立。八路齐全后通过当前最终筛选的比例在 E1/E2/E3 为 47.5%/37.8%/42.3%，相邻时段合并后为 30.1%/35.5%/35.4%；新增完整配对没有被后续条件全部剔除。

## 前后时段拆分

合并前后时间会掩盖时间变化。下表依次列出增强前、增强中、增强后，包数由每包 62 个事件槽位的总数重建；A 一路触发数每秒等于每秒下传包数乘每包 A 一路触发数。

| 增强窗 | A 下传一路触发 (s⁻¹)，前 / 中 / 后 | 下传包 (s⁻¹)，前 / 中 / 后 | A 一路触发 / 包，前 / 中 / 后 | 当前最终 / 一路触发，前 / 中 / 后 |
|---|---:|---:|---:|---:|
| E1 | 887 / 755 / 932 | 16.50 / 14.41 / 17.02 | 53.79 / 52.38 / 54.74 | 0.024% / 0.817% / 0.022% |
| E2 | 937 / 805 / 940 | 17.09 / 15.61 / 17.30 | 54.85 / 51.58 / 54.35 | 0.035% / 0.439% / 0.026% |
| E3 | 951 / 845 / 774 | 17.22 / 16.08 / 15.10 | 55.20 / 52.59 / 51.24 | 0.013% / 0.203% / 0.099% |

E1 和 E2 的增强中触发率比前、后都低；E3 的增强中低于前段，却高于后段。三个增强窗的下传包率均较前段低，每包 A 触发数也较前段低，因此不能把差异全部归因于下传包数。E3 后段的最终比例仍为 0.099%，明显高于前段的 0.013%；它像是增强的尾段，不能称为已验证的 quiet 对照。现有下传数据**不支持**“增强时 A 下传单路触发率升高”这一简单预测；也没有测到前端未下传的触发数，无法检验前端触发是否升高。

## 按下传触发率分组

对全时段 467 个有 A 一路触发记录的五分钟箱，独立按下传触发率分成四个等大小组。此分组不依赖 E1–E3 事件窗。

| 触发率组 | 触发率中位数 (s⁻¹) | 各箱最终比例的中位数 | 合并计数后的最终比例 |
|---|---:|---:|---:|
| Q1 | 339.3 | 0.1166% | 0.1092% |
| Q2 | 785.5 | 0.1232% | 0.2404% |
| Q3 | 950.2 | 0.00750% | 0.0605% |
| Q4 | 962.6 | 0.00449% | 0.0367% |

这不是单调关系：Q2 的合并比例最高，但最高触发率组 Q4 的比例较低。逐箱触发率与最终比例的 Spearman 相关系数约为 −0.418，仅作描述，不把相邻五分钟箱当成独立样本做显著性判断。这里的横轴与每箱下传包数高度相关，且最高速率已接近下传平台，因此不能据此推断“前端触发越强，最终筛选效率越低”。

## 物理解释与限制

离子污染没有预先确定的最终比例方向：若主要增加单路信号，分母可能增长得更快；若增加能形成八路配对、且满足定时和空间条件的记录，最终比例也可能升高。此次预选 ENA 增强窗显示更多完整配对及更高的最终产出比例，与离子造成更多配对的设想相容；但它同时显示更低的 A 下传单路触发率，不能声称“高触发率”这一部分假说已得到验证。这些窗口本来就按 ENA 增强选取，不能作为离子来源的独立验证。全时段按下传触发率分组的低通过率，讨论的是另一个量，不能和事件窗比较混为一谈。

本分析没有 A 探头未下传的前端触发计数，也没有鹊桥二号所在位置的原位离子密度。THEMIS-B 的等离子体测量位于另一处，无法直接判定鹊桥二号是否处于高密度离子环境。高计数可能还包括偶然符合或仪器/遥测选择效应；仅凭这些筛选比例，不能区分局地离子、真正 ENA 与随机叠加。
