# GENA raw 转换固定规则 v1

版本：`gena-raw-v1.0.0`。核查日期：2026-10-27。这个版本用于建立可复现的原始遥测处理基线；它固定字段解释、筛选顺序、拒绝条件和输出审计信息，不能代替新的在轨标定。

## 先给结论

当前 `l1a_2_l1b` 的 method 1 和 method 2 不进入科学生产链。两种旧算法都存在未定义名称、错误掩码和时间基准破坏；更关键的是，它们把起始和截止信号分别平移到同一个和常量，普通 L2 入口随后会把原始飞行时间变成零。修复算法的代码错误可以修好，但仅靠代码修好不能证明所假定的异常机制真实，因此 v1 对异常通道只保留原始值、诊断列和拒绝统计。

生产入口是 `gena.raw.pipeline.process_raw(raw_file, output_folder, snid=1)`，命令行入口是 `python -m gena.raw.frozen_raw RAW_FILE OUTPUT_FOLDER`。输出目录必须不存在；程序先写临时目录，全部校验通过后一次性改名发布，不能向旧产品追加。原始文件在处理期间若大小或修改时间改变，整次处理失败。

## 产品级别的物理含义

| 级别 | 输入和处理 | 允许回答的问题 | 不允许的解释 |
| --- | --- | --- | --- |
| Raw | 原始二进制字节，保持原文件 | 原始数据是否可追溯 | 不能把文件大小当作有效粒子数 |
| Packet | 2064 字节固定帧，通过同步字、APID、长度、毫秒范围和字节和校验 | 哪些帧可无歧义解包 | 通过校验不等于每个事件槽都有粒子 |
| L0 | 每个唯一合格包展开 62 个事件槽，保留原码和 `is_empty_slot` | 哪些槽位被记录、哪些是结构性全零 | 不能把零填槽当作低能信号 |
| L1 | 按 A/B 探头和 `snid` 通道映射把 TDC/EP 原码换成 ns/EP | 哪些槽的通道值被记录 | 没有八通道完整性和物理一致性保证 |
| L1A | L1 中八个位置计时通道均为有限正值的行，并附加同一包工参和姿态状态 | 哪些事件具备计算位置和能量的输入 | 八通道完整不等于 ENA 真事件；姿态无效的行仍会保留并标记 |
| L2 | 对全部 L1A 计算位置、角度、各轴 TOF、电子修正 TOF、种类和能量 | 原始完整事件的派生量和失败原因 | L2 全表不是筛选后的科学样本，也不是通量产品 |
| L2S | L2 中通过起始长度、起止顺序、起始和、起始差、截止差五项时间检查的行 | 时间结构一致的候选事件 | 不代表 X/Y TOF、姿态和能量都已验证 |
| L2G | L2S 再通过 X/Y TOF 比值、探测器窗口、有限正能量和姿态有效性 | v1 的科学分析候选集 | 不能单凭计数增加或图像变集中证明修复正确 |
| L1B/L2B | 预留给经过独立物理验证的修复分支 | 未来审计和对照 | v1 不自动生成，也不把推定通道写入黄金样本 |

L2 中同时保存 `Q_*` 独立掩码和 `Q_Soft`、`Q_Gold` 累积结果。`Q_Aperture` 使用当前物理窗口参数，只作诊断列；在有效面积和边缘响应完成标定前，它不参与 `Q_Gold`。这样可以区分“通过某一项检查”和“进入固定科学样本”。

## 包级审计规则

每个包必须满足同步字 `e2 25 0c 4e`、APID `0x0c4e`、固定数据长度 `2055`、毫秒字段小于 `1000`，以及原始字节偏移 `[8,2062)` 的 8 位字节和模 `65536` 等于末尾大端校验字。包的顺序、14 位计数跳变和时间先后只作诊断，不作为自动拒绝条件，因为回绕、重传和乱序都是可能的遥测状态。

包身份是完整 2064 字节的 SHA-256；同一输入文件内重复包只保留第一份进入 L0/L1，所有候选包仍写入 `packet_inventory`。无法通过校验的包写入 `rejected.jsonl`，并保留偏移和失败原因。文件尾部含完整同步字但不足 2064 字节时记录 `truncated_tail`，产品状态为 `complete_with_exclusions`。

## 数值和筛选规则

TDC 原码小于等于 94 按当前软件约定记为无测量并转换为零；大于 94 的值按 `(code - 94) × 0.081 ns` 转换。原始原码仍保存在 L0，零值不被当作精确计时。EP 原码 `0` 和 `4095` 转换为零，有限的 `1..4094` 按 `(2044-code) × 100/123` 转换，越界和非有限值为 NaN。

探头映射固定由 `snid` 和探头标志共同决定，不能按通道数值大小交换两端。`Tof_1` 是主 TOF 槽；`Tof_X`、`Tof_Y` 由对应起止两端和之差除以二得到。最终 `Tof` 只有在主 TOF 与两轴一致，或两轴之间满足绝对/相对一致性时才保留正有限值；否则为 NaN。无效高压不外推电子飞行修正。

工参使用同一包时间的 PDF 值，不跨包插值。姿态和位置只在相邻有效样本间隔不超过 60 秒时插值；姿态使用 SLERP，位置线性插值，范围外不外推；重复时间戳且姿态值冲突时整组无效。`PoseValid` 单独写入 L1A/L2，L2G 要求它为真。

## 修复和补全边界

原始资料支持检查共同时间零点偏移、TDC 模计数回绕、起止槽位混入和单通道缺失等候选机制，也支持用另一方向的和关系产生候选值。它没有证明任意异常事件都能唯一恢复。只有在缺失通道身份、共同时标、和常量版本、回绕选择以及未参与求解的几何约束都独立确定时，候选才可以进入后续验证；多个候选同时通过时必须保留歧义并拒绝自动纳入科学计数。

因此 v1 采取以下固定策略：完整八通道事件进入 L1A/L2；不完整事件保留在 L1 并计数；任何推定值不覆盖原始列；不生成 L1B/L2B；旧 method 1/2 通过 `NotImplementedError` 明确阻断。未来若启用修复，必须新增 profile 版本、逐事件候选列、独立遮蔽/扰动验证和真实样本的唯一率、歧义率、拒绝率报告。

## 验收标准

验收至少包括：完整事件八个计时值、TOF、位置、能量前后一致；TDC 最大码、原码 0/94、无效高压和 NaN 不产生伪造能量；坏包和截断尾可追踪；相同 Raw 在不同 `chunk_packets` 下包 UUID、行数和产品哈希一致；重复执行不会覆盖已有目录；L2S/L2G 的每个 `Q_*` 掩码都能从 L2 原行复算。真实遥测验证仍需按探头、工参稳定段和日期报告，不用合成样本替代在轨真值。

来源证据、旧算法反例和未冻结的仪器事实见 [source_review.md](source_review.md) 与 [repair_comparison.json](repair_comparison.json)。一个真实 Raw 文件的包完整性和筛选漏斗结果见 [real_sample_audit.json](real_sample_audit.json)。
