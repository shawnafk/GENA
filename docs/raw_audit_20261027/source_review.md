## 2. 原始资料已经说明了什么

### 2.1 时间零点平移应保持飞行时间

S6 的 P2–7 把异常描述为通道“基准线”跳动、单路或多路整体偏移，并据同一短时段的分布一致性提出平移方法。这是对在轨统计现象的解释，尚不能单独证明每个异常事件均来自同一粒子。

S6 “数据平移方法”流程图（P10 图像）明确写出四步：截止小于起始时先加 `8192 × 0.081 ns`；计算 X/Y 起始两端和及其相对物理线长的倍数；平移起始信号；再根据新旧起始信号的变化重算截止信号。第四步附注为“该过程保证了飞行时间不变”。P9 同时说明不改变起始/截止的相对位置，即保持方向信息。流程图还注明平移结果为负时不改变初始值，因此不能仅凭该图推出所有事件都有同一个连续平移规则。

S6 P24–27 的结论明确带有“暂时可归纳（仍需进一步分析）”：平移对大量粒子信号事件效果不大，对 A 更明显，方向图在部分事件改善、磁暴期间例外。它给出了典型事件图像，但没有逐粒子真值、假阳性率或恢复误差分布。

### 2.2 放宽起始和有条件，任意补全效果不稳定

S7 的 2A 规则包含起始两端和、两端差位置边界、起始 `90 × 30 mm`、截止 `145 × 55 mm`、以及 `abs(TOF_X - TOF_Y) < 5 ns`。其文字将 X/Y 起始和都写为 `50 ns`，而 S6 对 X/Y 合理单路范围写为 `0–50 ns`、`0–40 ns`，当前标定表也按探头和方向区分。故 S7 的 50 ns 只能作为该文当时的处理说明，不能覆盖当前标定常数。

S7 的 2B 节取消了起始和限制，理由是采样计时零点可能偏移，但保留两端差、两个平面边界和 X/Y TOF 一致性。该节记录数据量增加约一个数量级以上。这支持检验“同轴共同偏移且起止差保持”的事件族，并不支持删除全部物理一致性检查。

S7 的 2E 节说明按 256 种情形补全，对原始来源不作限制，再检查补全后规则；计数也增加约一个数量级。2F 节先要求原始起始 X/Y 两端差落在有效边界，再补全并执行同样的最终条件，文中记录其数据量与 2A 基本一致。这个对照说明补全增量高度依赖原始条件。补全公式主动强制满足的和、TOF 一致性不能再算作独立证据。

S7 的 2A/2B/2E/2F 是该历史分析的自定义名称，不能与当前仓库 `l2`、`l2b`、`l2g` 或正式预处理文件中的 2A/2B 自动等同。

### 2.3 异常机制有竞争解释

S1 第 4 页记录 Tof0/Tof1 有翻转现象，但有效主 TOF 样本约千分之五，且不少 `Tof0 > Tof1` 实际对应 `Tof1 = 0`。这是该笔记样本的比例，不应外推到全任务。S1 第 6 页对 Lu 方法的 `max(offset_X, offset_Y)` 明确提出“必须相差不多”的疑问，也质疑只选距离零点更近的一端。

S1 第 7 页记录某样本 X 信号翻转约 46%、Y 约 6%，提出噪声先触发、真实粒子随后到达、截止溢出的解释；同页给出 633 ns，而第 6 页给出 663.47 ns，两个数字不一致，不能直接冻结为硬件定值。第 8–9 页提出真正起始可能填在截止槽，认为互补重建在数学上可行，同时追问“用哪个信号作为正确值修复”。

S2 第 2–4 页展示起始 X/Y 大数近同步、两端差仍集中的异常，以及起始估计零点约 517 ns 的单事件例子；文字仍以问句讨论它是 rollover 还是纯噪声。第 6–7 页提出 X 方向 FIFO 未刷新/串入前一粒子的截止信号，并记录多种互补匹配可能：`1e + 2s` 与 `2e + 1e` 均可能满足。FIFO 机制是解释假设，PPT 没有给出硬件复现或示波器证据。

S2 第 9–10 页显示 B 探头截止存在条带、多峰，配文含“纯噪声分布”“数据平移导致”；不能将所有条带都视为一项常量偏移。第 20 页强调错误并非短时现象，但仍询问其比例。

### 2.4 已有验证图能支持的范围

## 4. 保持 TOF 的方程

对一个方向 d，设两端正常传播时间和为 `C_d`，共同触发零点为 `τ_s`，截止对应时刻为 `τ_e`。同一粒子、同一时钟参考、尚未回绕且通道完整时：

```text
s1 + s2 = C_d + 2τ_s
e1 + e2 = C_d + 2τ_e
TOF_d = [(e1+e2) − (s1+s2)] / 2 = τ_e − τ_s
position_start = K_d (s1−s2) + B_d
position_end   = K_d (e1−e2) + B_d
```

同轴两端的共同平移 `s1'=s1−τ_s, s2'=s2−τ_s, e1'=e1−τ_s, e2'=e2−τ_s` 保持位置差和 `TOF_d`。X/Y 若采用各自的固定通道延时校正，也必须在各自起止信号上施加同一校正，并验证跨轴时标一致性。

旧 method1 的 `_repair_start` 分别将起始两端减去 `(s1+s2−C)/2`，起始和变为 C；共有 `_repair_end` 又将截止两端减去 `(e1+e2−C)/2`，截止和也变为 C。之后普通 `f_tof_mxy` 重算时：

```text
TOF_d_after = (C−C)/2 = 0
```

保存在中间列 `Tofe−Tofs` 中的原始时间差没有重新加回两个截止通道，普通 L2 入口也不使用该中间列。因而哪怕原始事件完全合理，也会失去飞行时间。用例 `C_X=50, τ_s=0, τ_e=30, s=(20,30), e=(45,65)` 的原 TOF 为 30 ns，旧步骤后 s=(20,30)、e=(15,35)，TOF 变为 0。位置差仍可能看起来合理，所以仅查看角度图不足以发现它。

旧 method2 的 `_repair_start_2` 把起始缺项补为 `C−另一端`，但没有建立 method1 的 `Tofs` 时标；它又复用 `_repair_end`，存在同样的 TOF 归零问题，并使需 `Tofe−Tofs` 的跨轴补全分支产生 NaN。两种方法还共用若干实现错误：`ns_2_xy` 未定义、最终重复检查 `start_valid`、部分分支把 Y 的和常量写成 CX、补 X2 时写入 X1、Type 掩码错位。修复这些代码错误是运行正确的必要条件，但不能证明所采用的异常机制真实。

## 5. 单通道何时可以唯一补全

若已独立确定“只有 X1s 缺失”，另外一轴的起始两端可信、共享触发时标、`C_X/C_Y` 的版本已确认，且没有回绕/槽位歧义，则：

```text
τ_s = (Y1s + Y2s − C_Y)/2
X1s = 2τ_s + C_X − X2s
```

若只有 X1e 缺失，Y 截止两端可信，则：

```text
τ_e = (Y1e + Y2e − C_Y)/2
X1e = 2τ_e + C_X − X2e
```

这是一项未知数的一条独立等式，解在既定异常假设下唯一。必须另外检查重建值有限、原码可表示范围/回绕选择、两平面边界、因果 TOF、未参与求解的原始通道约束，并记录“实测”和“推定”的区别。

以下情况不能仅靠一条和关系唯一恢复：缺失通道身份不清；对侧也可能是噪声；零点未知；X/Y 各有独立的触发偏移；两端同时缺失；同一端 s/e 是两个独立粒子；起始填在截止但原截止已丢失；多个候选交换/回绕方案都通过约束。仅“更接近零点”“位于小数区”“修复后落在板内”不足以选出唯一真解。

对 X1s 的上述补全，用 Y 起始和确定零点后，再要求补全后的 X/Y 起始零点相等是代数恒等式，不能当作又一项独立验证。同理，用 `TOF_Y` 填 X 的截止缺项后，得到 `TOF_X=TOF_Y` 只是构造结果。应报告候选数和用于求解/用于验证的条件，存在多个合格候选时保留歧义。

## 6. 固定规则与验证样本包应包含的内容

这些是依据上述证据提出的验收要求，并非已经完成的仪器标定结果。

1. 保存原始通道、探头/事件标志、包序/槽号、采样与阈值状态、标定版本；按完整正常、共同零点偏移、回绕候选、槽位替换候选、已知单通道缺失、不可辨识分别计数。结构性全零填充单列，不能充当低能粒子。
2. 完整正常事件作为不可变对照。除明确版本化的数值精度改进外，修复入口不得改变它们的八通道、TOF、位置、能量或分类。
3. 对已知正常事件进行单通道遮蔽、共同零点平移、模计数回绕等受控扰动，验证恢复误差及分类；A/B 和八个通道分别覆盖。合成扰动证明数学实现，不证明真实异常必属该机制。
4. 真实异常样本保留逐事件全部候选和拒绝理由，加入对向通道不可信、双路缺失、两种槽位匹配都成立、边界事件、原码 0/94、TDC 最大码、无效高压等反例。不能只挑选恢复成功的例子。
5. 检查全部输出 TOF 的正值/有限性、零峰、电子修正前后的分布、能量尾部、A/B 分布、起止位置边缘条带。S3/S5 表明“计数变多、图像变集中、互相关峰在零”不足以验收。
6. 对真实样本按工参稳定段、探头、日期分别报告原始可用率、唯一恢复率、歧义率、拒绝率、对照不变率；阈值调低产生的计数增加不得直接解释为空间环境变化。
7. 验证真正独立的残差，并通过在同一工参段打乱通道配对估计偶然符合背景。若误配对也大量通过，应调整规则或把该事件族降为仅供诊断，而非自动纳入科学计数。

文档不足以冻结的关键事实仍包括：在轨 TDC 溢出与采样窗口的精确关系、原码 94 的硬件语义、四个主 TOF 槽的顺序及有效标志、FIFO 异常机制、最新在轨通道映射和各方向时延标定。这些应保留为可追踪的参数与假设，避免通过一次全量重算把不确定性固定进科学产品。
