# Repository Instructions

## Markdown formatting

- Do not hard-wrap Markdown prose according to line length.
- Keep each prose paragraph on one continuous source line.
- Insert source line breaks only where Markdown structure requires them, including paragraph boundaries, headings, lists, tables, blockquotes, and code blocks.

## Things you should never do

- 数据契约这个词不要用，正常人都用数据格式
